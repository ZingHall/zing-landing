# Platform Architecture

Zing Protocol is a creator monetization platform built on the Sui blockchain that enables creators to own their content, monetize through memberships and donations, and leverage decentralized storage with hybrid search retrieval. This page dives into the technical architecture that makes this possible. {{ className: 'lead' }}

## System Overview

The Zing Protocol platform consists of several integrated layers:

- **Sui Blockchain** - Core transaction and ownership layer
- **Walrus Protocol** - Decentralized storage for content blobs
- **Seal Protocol** - Encryption for tiered content access
- **Search & Retrieval** - Hybrid vector + lexical search with cross-encoder reranking for AI agent queries
- **zkLogin** - Web2-style authentication without seed phrases

## Core Components

### zkLogin Authentication

zkLogin enables Web2-style authentication using Google OAuth. No seed phrases required.

```typescript
// Authentication flow
const login = useWalletStore((s) => s.login)
await login('google') // Triggers Google OAuth

// Session persisted via zkloginStorage (Zustand)
// Contains: jwt, suiAddress, maxEpoch, ephemeralSecretKey, zkProof
```

### Walrus Protocol Storage

Content is stored on Walrus, a decentralized storage system on Sui. Each blob is identified by a unique ID. Content is automatically chunked, embedded, and indexed into the hybrid search pipeline when published.

```typescript
// Storage cost calculation
const { encodedSize, writeCost } = storageCost(
  walrusSystemState,
  totalSize,
  epochs, // Default 2 epochs
)

// Storage tiers
// Basic: ~5 GB (Free)
// Premium: ~20 GB ($X/month)
// Premium+: ~100 GB ($XX/month)
```

### Seal Protocol Encryption

Content access is controlled via Seal Protocol encryption. Members receive decryption keys based on their membership tier.

```typescript
// Access tiers
Public    → No encryption (anyone can read)
Basic     → Basic members only
Premium   → Premium members only
Ultra     → Ultra members only
```

### Search & Retrieval (RAG Pipeline)

Content is automatically indexed into a hybrid search pipeline combining vector embeddings, lexical retrieval, and cross-encoder reranking.

```
Query
  │
  ├──► Vector Search (pgvector HNSW, 256-dim)
  │    - Embedding via potion-multilingual-128M
  │
  ├──► Lexical Search (pg_bigm + ts_rank_cd)
  │    - Bigram ILIKE + PostgreSQL full-text
  │
  └──► RRF Merge (k=60) → Cross-encoder Rerank
       - bge-reranker-v2-m3 (ONNX quantized)
       - Results filtered by relevance score
```

## API Integration

The Zing API is built on the Sui blockchain with RESTful endpoints:

```bash
# Base URL
https://api.prod.zing.you

# Search Base URL
https://search.zing.services/

# Key endpoints
GET  /articles          # List articles
POST /articles          # Create article
GET  /memberships       # List memberships
POST /subscribe         # Subscribe to creator
POST /donate            # Donate to creator
GET  /wallet/balance    # Get USDC balance
POST /wallet/topup      # Top up wallet
POST /wallet/payout     # Withdraw funds
```

## Data Flow: Content Creation

```
Creator → Write Content (TipTap Editor) → Configure Access Tier
    ↓
Calculate Storage Cost (Walrus) → Encrypt with Seal
    ↓
Publish Transaction (Sui) → Upload to Walrus → Get Blob ID
    ↓
Content Available → Members can access based on tier
```

## Data Flow: Membership

```
Member → Browse Creator → View Locked Content
    ↓
Click Subscribe → Select Tier → Sign Transaction
    ↓
Payment (USDC) → Update Membership Status (Sui)
    ↓
Grant Access → Decryption Key Provided → Content Accessible
```

## Pages & Features

The Zing web app provides creators and readers with the following pages:

| Page | Features |
|------|----------|
| **Home** | Tag sphere for browsing related articles by topic. Search bar with semantic + keyword search (Google-like). Content feed. |
| **Explore Creators** | Discover creators by tags. Search creators by name. Browse creator profiles and their content. |
| **My Posts** | Manage your published articles. Create, edit, and delete content. |
| **Creator** | Creator profile page with member management and content oversight. |
| **Earnings** | Full earnings dashboard — subscription revenue, API/chunk retrieval revenue, donation revenue. Configure content fee rates and subscription fee settings. |
| **Plans** | View your subscription status across creators. Upgrade or downgrade membership tiers. |
| **Wallet** | USDC balance management. Deposit and withdraw funds. Transaction history. |
| **Referral** | Referral program information and commission tracking. |

## Revenue Model

| Stream | Description |
|--------|-------------|
| **Memberships** | Recurring USDC subscriptions (tiered access: Basic, Premium, Ultra) |
| **Donations** | One-time USDC payments with optional messages |
| **API / Chunk Retrieval** | Token-based micro-payments for AI agents accessing content chunks |
| **Referrals** | Commission-based rewards for referring new creators |
