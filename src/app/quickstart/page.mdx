# Quickstart

Welcome to Zing Protocol! This guide will get you set up and ready to start monetizing your content as a creator. We'll cover authentication, studio activation, and publishing your first article. {{ className: 'lead' }}

## Prerequisites

Before you begin, you'll need:

- A Google account for authentication
- A Sui wallet (optional for topup usage, more topup options coming soon)
- USDC for purchasing storage tiers other than free plan

## Step 1: Authenticate with Google

Zing Protocol uses zkLogin for seed-phrase-less Web3 onboarding. Simply click "Continue with Google":

## Step 2: Activate Your Studio

After authentication, you'll be prompted to activate your Studio. This involves:

1. **Choose a Storage Tier** - Select Basic (free), Premium, or Premium+
2. **Set Your Prices** - Configure membership prices for each tier
3. **Complete Purchase** - Pay with USDC balance

```bash
# Storage tiers available
Basic    → ~5 GB storage (Free)
Premium  → ~20 GB storage (Monthly fee)
Premium+ → ~100 GB storage (Monthly fee)
```

## Step 3: Create Your First Content

Navigate to the content editor to create your first article:

1. **Compose** - Use the TipTap rich text editor
2. **Configure** - Set access tier (Public, Basic, Premium, Ultra)
3. **Preview** - Review how your article will appear
4. **Publish** - Upload to Walrus storage

```bash
# Access tiers determine who can view your content
Public   → Anyone can view
Basic    → Basic members and above
Premium  → Premium members and above
Ultra    → Ultra members only
```

## Step 4: Set Up Your Profile

Customize your creator profile to attract members:

1. **Upload Avatar** - Your profile picture
2. **Add Bio** - Tell members who you are
3. **Set Membership Prices** - Configure tier pricing
4. **Add Social Links** - Connect your other platforms

## Understanding the Dashboard

After studio activation, you'll have access to:

| Section      | Purpose                         |
| ------------ | ------------------------------- |
| **Home**     | Your content feed and analytics |
| **Create**   | Content editor (desktop only)   |
| **Explore**  | Discover other creators         |
| **Wallet**   | Manage USDC balance             |
| **Earnings** | View revenue and transactions   |
| **Referral** | Track referral commissions      |

## Troubleshooting

<Note>
  **Authentication Issues**: If Google auth fails, try clearing cookies and
  localStorage, then attempt again.
</Note>

<Note>
  **Storage Limit Exceeded**: If you hit your storage limit, upgrade to a higher
  tier or delete old content.
</Note>

<Note>
  **Transaction Failed**: Ensure you have sufficient USDC balance for the
  transaction fee (~$0.001).
</Note>
