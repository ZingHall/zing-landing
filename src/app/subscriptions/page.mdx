# Subscriptions

Zing Protocol's subscription system allows creators to monetize their content through tiered access. Subscribers pay USDC to access premium content from their favorite creators. {{ className: 'lead' }}

## Subscription Tiers

Creators can configure up to 3 subscription tiers:

| Tier        | Storage | Typical Price    | Purpose           |
| ----------- | ------- | ---------------- | ----------------- |
| **Basic**   | ~5 GB   | Free or low cost | Casual supporters |
| **Premium** | ~20 GB  | $5-20/mo         | Active fans       |
| **Ultra**   | ~100 GB | $20-100/mo       | Super fans        |

## The Subscription Model

### Properties

<Properties>
  <Property name="id" type="string">
    Unique identifier for the subscription.
  </Property>
  <Property name="subscriber" type="string">
    Sui address of the subscriber.
  </Property>
  <Property name="creator" type="string">
    Sui address of the content creator.
  </Property>
  <Property name="tier" type="enum">
    Subscription tier: `basic`, `premium`, or `ultra`.
  </Property>
  <Property name="price" type="string">
    Subscription price in USDC (e.g., "5.00").
  </Property>
  <Property name="created_at" type="timestamp">
    Timestamp when subscription started.
  </Property>
  <Property name="expired_at" type="timestamp">
    Timestamp when subscription expires.
  </Property>
  <Property name="status" type="enum">
    Status: `active`, `expired`, or `cancelled`.
  </Property>
</Properties>

## Subscribe to Creator {{ tag: 'POST', label: '/v1/subscribe' }}

<Row>
  <Col>

    Subscribe to a creator at a specific tier. This creates a recurring subscription.

    ### Required attributes

    <Properties>
      <Property name="creator" type="string">
        The Sui address of the creator to subscribe to.
      </Property>
      <Property name="tier" type="enum">
        Subscription tier: `basic`, `premium`, or `ultra`.
      </Property>
    </Properties>

    ### Transaction fees

    A small transaction fee (~$0.001) applies for the Sui blockchain transaction.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/subscribe">

    ```bash {{ title: 'cURL' }}
    curl https://api.zing.protocol/v1/subscribe \
      -H "Authorization: Bearer {jwt_token}" \
      -d creator="0x123...creator" \
      -d tier="premium"
    ```

    ```js
    const subscription = await client.subscriptions.subscribe({
      creator: '0x123...creator',
      tier: 'premium',
    });
    ```

    ```json {{ title: 'Response' }}

      "creator": "0x123...creator",
      "tier": "premium",
      "price": "10.00",
      "created_at": 1709312400,
      "expired_at": 1711990800,
      "status": "active"

    ```

    </CodeGroup>

  </Col>

## Subscription Flow

```
User views locked content
         ↓
Content shows paywall with tier badge
         ↓
User clicks "Subscribe" button
         ↓
Subscription dialog shows available tiers
         ↓
User selects tier and confirms
         ↓
Transaction: USDC deducted from wallet
         ↓
Subscription created on Sui blockchain
         ↓
Access granted to content
         ↓
User can view full content
```

## Subscription Pricing

Creators set their own prices for each tier:

```typescript
// Example pricing configuration
const pricing = {
  basic: {
    storage_gb: 5,
    price_usdc: '1.00', // $1/month
  },
  premium: {
    storage_gb: 20,
    price_usdc: '10.00', // $10/month
  },
  ultra: {
    storage_gb: 100,
    price_usdc: '50.00', // $50/month
  },
}
```

## Revenue Model

| Stream            | Fee Structure                |
| ----------------- | ---------------------------- |
| **Subscriptions** | 95% Creator / 5% Platform    |
| **Donations**     | 95% Creator / 5% Platform    |
| **Referrals**     | 5-10% commission to referrer |

<Note>
  **Platform Fee**: Zing Protocol takes a 5% platform fee on all transactions to
  support platform development.
</Note>
